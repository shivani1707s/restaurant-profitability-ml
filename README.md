
# Multi-Channel Restaurant Profitability Prediction & Optimization

An end-to-end Machine Learning and Business Analytics project for analyzing and predicting restaurant profitability across multiple sales channels.

## Problem

Restaurants operating across in-store dining, Uber Eats, DoorDash, and self-delivery need to understand how commissions, operating costs, COGS, and delivery expenses affect profitability.

## Objectives

- Analyze channel-wise profitability
- Calculate profit and margin KPIs
- Identify major profitability drivers
- Build machine learning models to predict profitability
- Perform what-if cost simulations
- Develop an interactive Streamlit dashboard

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- SHAP
- Streamlit
- Jupyter Notebook
